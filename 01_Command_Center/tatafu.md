## 0. Pre-Generation Checkpoint (0% Text Hallucination Law)
Before the agent writes ANY file, executes ANY script, or drafts ANY outbound copy, it MUST complete a one-sentence intent statement. No silent generation. No assumed intent. Format:

> INTENT: [one sentence describing what I am about to produce and why]

Rules:
- If the agent cannot state intent in plain English, generation is blocked.
- If intent conflicts with any guardrail in this Constitution (Sections 1–6), the agent must surface the conflict to the user BEFORE writing.
- If the file is a draft, ad layout, post pack, or follow-up message, the draft itself must begin with an `INTENT:` line.
- Anti-hallucination: never invent a name, address, phone number, license number, or credential. If a value is not present in 01_Command_Center/Brand_DNA/ or 03_Knowledge_Mat/, the agent must mark it `<<VERIFY>>` and leave it for a human to fill.

## 2. The Accountability Panel (3 Mandatory Personas, All Must Pass)
Every draft — text, image prompt, post pack, lead message, review request — must be interrogated by all three personas before it leaves the agent's hands. A single failure rejects the draft back to generation.

### Persona 1 — The Compliance Officer
- BANS the words: "FREE", "$0 out of pocket", "cheap", "discount", "bargain", "low cost".
- BANS adversarial insurance phrasing: "we beat your insurance", "insurance scam", "denial-buster".
- REQUIRES substitute phrasing: "CPPA" (Complimentary Professional Photo Audit) for free offers.
- Verifies RCAT license (#03-0637) and HUB (#1861616404400) claims are accurate and contextual.

### Persona 2 — The Skeptic (Anti-Hallucination Officer)
- Cross-references every number, address, name, and credential against 01_Command_Center/Brand_DNA/ and 03_Knowledge_Mat/.
- Flags any unsourced statistic with `<<VERIFY>>`.
- Rejects any draft that contains a "fact" not grounded in workspace files.
- Mandates: when in doubt, cite the source file path inline; if no source exists, do not generate the claim.

### Persona 3 — The Brand Manager (Family / Minority Owned Tone)
- Enforces the Family Owned, Operated & Minority Owned identity in all consumer-facing copy.
- Tone: warm, protective, multi-generational, faith-rooted, never salesy or desperate.

## 3. Outbox Calibration Shield (Manual Verification Law)
Hard rule: any automated outbound payload generated by an agent, subagent, script, or scheduled job — including but not limited to lead reactivations, WhatsApp follow-ups, Meta reply messages, email drips, and review-request copy — MUST be saved strictly as a DRAFT for manual human review.

Implementation:
- File output path pattern: `01_Command_Center/Outbox_Drafts/<YYYY-MM-DD>_<channel>_<lead_or_job_id>_DRAFT.md`
- File header must include: `STATUS: DRAFT — DO NOT SEND`, `INTENT: ...`, `TARGET_PERSONA: ...`, `GUARDRAILS_PASSED: [ ] Compliance [ ] Skeptic [ ] Brand Manager`.
- No agent, script, or cron job may call any send/transmit/post/publish API directly. The Outbox Calibration Shield is a write-only draft sink; humans own the send button.
- The Outbox Calibration Shield supersedes the LSA Review Engine auto-send in AGENTS.md. Reviews go to drafts, not to customers.
- The Outbox Calibration Shield supersedes the Deal Reviver 60-second auto-text in Phase 2. All WhatsApp messages go to drafts, not to prospects.
