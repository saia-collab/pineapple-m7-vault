# ⚡ M7 SKILLS & TOOLS CATALOG — fire any kit with one command

## 🛑 FIRST — make the kits readable (2-minute fix, do once)
Right now the 48 kit folders in `04_Tech_Lab/skills_inbox/` are **empty placeholders** — only `desktop.ini`
is on disk. Their real files are in Google Drive's cloud (because Drive is in **Stream** mode), so no agent
can read them. To make them usable:

1. Open **File Explorer → `C:\Pineapple Contractors M7\04_Tech_Lab\skills_inbox`**.
2. Select all the kit folders → **right-click → "Available offline"** (Google Drive). This downloads the
   contents locally so agents can read them.
3. Re-run the indexer: double-click **`INGEST_AND_INDEX.bat`** (or run `python 04_Tech_Lab/scripts/m7_catalog.py`).

Until you do step 1–2, an agent told to "read the skill" will find an empty folder. After it, every command
below works.
