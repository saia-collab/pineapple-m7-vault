# 🎛️ M7 Operating System — Cadence + Routing

## 🧭 PART 1 — WHO EXECUTES WHAT (the routing decision)
The video's smart-routing idea is right: match the task to the cheapest tool that can do it well. Here's YOUR map:

| Task type | Route to | Why |
|---|---|---|
| Brand copy, captions, page/blog writing, schema, validation, planning | **Claude (me)** | No cap, knows brand law, reliable |
| **Big multi-step projects** (domain merge, Drive media reorg, bulk site edits, design builds) | **Claude Cowork** | Cloud + Drive/web connectors, runs a whole project hands-off |
| **Bulk drafts / keyword lists / autonomous loops** | **Hermes Goal Mode** (on OmniRoute/free API) | Free, autonomous — then I firewall the output |
| Free routing to dodge rate limits | **OmniRoute** (`auto`) | 1 endpoint → 237 providers, auto-fallback when one runs dry |
| Coding/technical (when not rate-capped) | **Codex / GPT 5.6** or me | Codex is capped often — don't rely on it |
| **Memory** (never re-explain the business) | **Obsidian vault** (auto) | Agents read + update it every session |

**The rule:** Claude = quality/brand. Cowork = big projects. Hermes/OmniRoute = free bulk. Obsidian = memory.
