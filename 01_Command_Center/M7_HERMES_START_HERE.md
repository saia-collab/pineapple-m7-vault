# 🍍 HERMES — START HERE (you're new, this is everything)

Breathe. You have 3 windows open. Here's what each one is and what to do. You only ever
*type* into ONE of them (Hermes). The others just run in the background.

## THE 3 WINDOWS (what they are)
| Window | What it is | What you do |
| :--- | :--- | :--- |
| **M7 Engine** (says "ENGINE ACTIVE / localhost:3939") | the dashboard server | leave it open, don't touch |
| **M7 Brand Firewall** (says "watching 6 Fala rooms") | the compliance guard | leave it open, don't touch |
| **Hermes Agent** (the gold "HERMES-AGENT" window) | your AI worker | **this is where you type** |

> If you ever see a red `EADDRINUSE :3000` error → the Engine is already running in another window.
> Just close the error window. Never start the Engine twice.

## WHAT IS HERMES (in one line)
A worker that reads your vault, edits files, runs your scripts, and schedules tasks.
You tell it a goal in plain English in the box that says **"What should we tackle?"** — it does the work.
**It never publishes ads or sends texts on its own. Everything it makes waits for you in `Outbox_Drafts`.**

## ▶ YOUR FIRST 3 HERMES TASKS (copy-paste, in order)
Type these one at a time into the Hermes box. Wait for each to finish.

**Task 1 — let Hermes learn your business (do this first, once):**
```
Read these files and remember them as my operating rules for everything you do:
01_Command_Center/GROUNDING.md, MASTER_PLAYBOOK.md, M7_LEAD_ENGINE.md, M7_GROWTH_ENGINE.md.
Then give me a 5-bullet summary of what my business is and your rules. Do not change any files.
```

**Task 2 — your first real win (review requests):**
```
Read 01_Command_Center/M7_LEAD_ENGINE.md. Using the review-request text in it, write 3 sample
review-request messages (use placeholder names) and save them to 01_Command_Center/Outbox_Drafts/
as PAUSED drafts. Do not send anything. Then list what you created.
```
→ Open the files it made, read them, and that's your template to text real customers.

**Task 3 — have Hermes write your 30-day gameplan:**
```
Based on 01_Command_Center/MASTER_PLAYBOOK.md, M7_GROWTH_ENGINE.md, M7_LEAD_ENGINE.md, and
M7_CONTENT_FACTORY.md, write me a simple 30-day marketing gameplan for Pineapple Contractors
(roofing). One focus per week, 3 daily actions max, written for someone with ADHD. Save it to
01_Command_Center/Outbox_Drafts/30_Day_Gameplan.md. Keep every rule (CPPA not free, no green,
ad spend stays manual).
```

## THE BATCH FILES (when to double-click each)
You rarely need these. Here's the whole list:
| File | When |
| :--- | :--- |
| `RUN_AGENT_OS.bat` | start of a work session (opens Engine + dashboard) — only if not already running |
| `LAUNCH_ALL.bat` | to start Hermes + everything together |
| `INGEST_AND_INDEX.bat` | after you drop files into `skills_inbox` |
| `REGISTER_DAILY_SYNC.bat` | ONCE — turns on the daily auto-update |
| `M7_CLEANUP.bat` | if the folder looks messy |

## THE DASHBOARD (localhost:3939)
Open a browser → `http://localhost:3939`. It shows your AI fleet, the avatars, and a task runner.
You don't *have* to use it — it's the visual view. Hermes + the Outbox folder are what matter.

## 📅 YOUR 30-DAY PLAN (simple, one focus per week)
**Week 1 — Foundation (don't skip):**
- Run Hermes Tasks 1-3 above.
- Fix the website + GBP: "free" → "Complimentary Professional Photo Audit," phone 972-928-0788 everywhere.
- Turn on LSA lead alerts to your phone. Reply to every lead in 5 minutes.

**Week 2 — Reviews engine:**
- Start texting every finished customer for a Google review (use the Task 2 template).
- Log every lead in the CRM `Google_LSA_Leads` tab.
- Pick 1 testimonial clip from your media → post it (GBP + Reel).

**Week 3 — First ad:**
- Review the Storm Launch campaign in `Outbox_Drafts`. Launch the Local Fan ad set ($250/week) in Meta.
- 2 GBP posts + fresh photos from your media.

**Week 4 — Track + double down:**
- Run the weekly review (which source booked the most JOBS). Put next budget on the winner.
- 5 media clips → ads (Content Factory). Keep the review texts going.

## 🛟 IF YOU FEEL LOST
Do ONLY this: (1) answer LSA leads in 5 min, (2) text finished customers for a review,
(3) ask Hermes one task from above. That's the whole business. Everything else is bonus.
