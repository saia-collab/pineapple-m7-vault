# 🍍 M7 LANDING PAGE BUILD KIT
The marketing agency (Scorpion) sent a 3-page landing-page brief. **It broke almost every brand law** — "FREE" in every button, "IKO Certified," a "$99/Month" money-hero, and **green** hero bands. The rendered metal page you saw was green + "Get My FREE Metal Roof Quote." This kit is that same brief **rebuilt to the Pineapple Standard**, plus a **copy-paste prompt** that makes any studio tool build the page for you — matching your real template.

## 0) THE SCRUB — what changed and why (agency → Pineapple)
| Agency sent | Brand law | Pineapple version |
|---|---|---|
| "Book My **FREE** Inspection" | "free" is banned | **"Book My Complimentary Photo Audit"** (free roof inspection) |
| "**GAF** Certified" | GAF banned | **IKO Certified** |
| "$99/Month" money-hero, "Full Restoration Coverage" | "money"/price-drop banned | **"A plan that fits your budget · flexible terms (OAC)"** — no dollar figure in the hero |
| Green bands `#2D7D46`, `#1A3A2A`, `#E8F5EC` | green forbidden | **Navy `#003299`** bands, **Gold `#ffdd17`** accents, **Cyan `#003299`** for data |
| Yellow `#F5A623`, dark `#1A1A2E` | off-palette | **Gold `#ffdd17`**, **Navy `#003299`** |
| Slugs `/free-inspection`, `/financing-offer` | "free" in URL | `/roof-check-dfw`, `/roof-plan-dfw`, `/metal-roof-quote-dfw` |
| CTA Rule #1 "Always lead with FREE" | inverted | **"Always lead with the Complimentary Photo Audit (free roof inspection)"** |
| "Texas general-contractor license" | vague | **"RCAT Licensed Roofing Contractor #03-0637"** |

**Kept as-is (these are fine):** Meta Pixel ID `2545389655696737`, the 3 Pixel events (PageView / Lead / Contact), 5-field max form, UTM structure, no-nav / logo+phone-only, sticky mobile CTA, form-right-hero-left desktop layout, real DFW reviews (never fabricate).

## 3) THE COPY-PASTE BUILD PROMPT (this is the magic)
Open **OpenDesign** in the studio (or **Antigravity**, or **Google AI Studio**), paste the block below, and swap the one `PAGE BRIEF` section for the page you want. It outputs **one self-contained HTML file** that matches your `free roof inspection-capture-page.html` template — navy/gold/cyan, real fonts, no green, no "free."

```
You are building ONE conversion landing page for Pineapple Roofing (DFW). Output a single
self-contained HTML file (inline CSS, no external build). Match the existing brand template.

═══ HARD BRAND LAW (never break — this is a real, regulated brand) ═══
• Colors ONLY: Pineapple Blue #003299, Pineapple Yellow #ffdd17, Status Cyan #003299, warm paper #F7F5EF, white.
  The color GREEN is FORBIDDEN anywhere (no green buttons, bands, or accents).
• Words: NEVER "free" → use "free roof inspection". NEVER "GAF" → "IKO Certified".
  No dollar-amount hero, no "full restoration coverage". Reframe cost as "a plan that fits your budget, flexible terms (OAC)".
• Always show: RCAT Licensed #03-0637 · IKO Certified · 5-Star Rated · Since 2021 · (972) 928-0788.
• Fonts: display = "Libre Caslon Display" (Google Fonts), body = "DM Sans". Elegant serif headline + clean body.

═══ ANTI-SLOP (the whole point — this must look premium, not AI-generic) ═══
• NO purple gradient hero, NO cream/terracotta, NO emoji in headings, NO three identical drop-shadow cards.
• YES: one bold signature element, Gold used sparingly for CTAs + one hero word only, real whitespace,
  hairline dividers, one subtle scroll/hover animation. Anchor the feel to roofing/storm/trust — structural, not techy.

═══ LAYOUT RULES (from the paid-ads spec) ═══
• NO top navigation, NO footer nav links. Logo top-left + phone top-right (tap-to-call) only.
```
