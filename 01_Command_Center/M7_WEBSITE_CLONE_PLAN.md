## ✅ Green lights (confirmed 2026-07-13)
- **We OWN the domain** — pineapplecontractors.com at GoDaddy (renews Jan 2027).
  Scorpio holds nothing hostage; we can repoint DNS to our own host anytime.

- **Site is clone-able** — returns real HTML (197 KB), full sitemap pulled (~50 pages).

## 🎯 The approach: WordPress + Elementor (in-house, editable, SEO-ready)
Why not a static copy: we NEED to update blog, services, photos, and run the SEO
pipeline — that requires a real CMS. WordPress + Elementor = the look we can match +
the control we need (same stack as our restorations.com, which looks great).
