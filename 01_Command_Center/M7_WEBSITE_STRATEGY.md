# 🏛️ CEO/VP DIRECTIVE — Website & SEO Consolidation

## The situation
Three roofing-related domains are live:
| Domain | Built on | Role | Cost |
|---|---|---|---|
| **pineapplecontractors.com** | Custom (Scorpio, AWS) | Ranking, GBP + LSA connected | $500/mo |
| **pineappleroofingllc.com** | New (brother) | Overlaps roofing | ? |
| **pineapplerestorations.com** | WordPress + Elementor | Restoration side (has Blog) | low |

## The problem (why this matters)
Two roofing sites competing for the same searches = **split SEO authority**. Google
divides trust between them, so neither ranks as high as one strong site would. This
is likely why our striking-distance keywords stall at position ~16. **More sites =
weaker rankings, not stronger.**

## 🎯 THE DIRECTIVE — One Money Site
1. **pineapplecontractors.com is the flagship.** It has the rankings, the GBP + LSA
   connection, and the professional build. ALL roofing SEO, content, and ad traffic
   concentrates here. This is non-negotiable for ranking.
2. **pineappleroofingllc.com** → do NOT run it as a second roofing site. Either:
   - **301-redirect** it to pineapplecontractors.com (passes any authority over), or
   - repurpose it for something non-competing (e.g. recruiting/careers only).
   Pick one; don't let it cannibalize the flagship.
3. **pineapplerestorations.com** stays as the restoration brand (different service,
   different keywords) — no conflict. Its WordPress blog is our easy content channel.

## 💵 On the $500/mo Scorpio site + "cloning it"
**Stop trying to AI-clone the Scorpio site.** We attempted it twice; it came out ugly.
Cloning a professional, lead-connected build with an AI generator will not match it,
and a broken clone would risk the leads it currently drives. Two honest paths:
- **KEEP Scorpio (recommended for now)** if the site produces leads. $500/mo for a
  site wired to GBP + LSA that ranks and converts can be worth it. Put our energy into
  content + leads, not rebuilding.
- **REPLACE later, done right** — only if we want to cut the cost: a proper WordPress
  build (like restorations.com, which looks good) on a premium roofing theme — a real,
  planned project, NOT an AI clone. Decide deliberately, not reactively.

## 🧰 What our AI OS is actually great for (use these, not website cloning)
| Goal | Tool / Agent |
|---|---|
| Find what to rank for | OpenSEO (live GSC data) |
| Write SEO pages / blogs | Hermes Goal Mode (free) |
| Publish to WordPress (restorations) | Hermes → WP REST API (auto-draft) |
| Reels from 39GB media | Video Editor → Blotato |
| Marketing graphics | Canva / Adobe skills / Thumbnails |
| Lead speed + reviews | M7 Lead Engine |
| Roofing content → contractors.com | draft here → hand to Scorpio to post |

**Rule:** the OS feeds and optimizes the sites. It does not rebuild the flagship.

## ✅ Decisions needed (you + brother)
1. Confirm **pineapplecontractors.com = the one roofing flagship.**
2. Decide **pineappleroofingllc.com** → redirect to flagship, or repurpose.
3. Decide **Scorpio**: keep (focus on content/leads) or plan a proper replacement later.
4. Ask Scorpio: **can they add SEO blog posts / edit service-area pages** for us? (That's
   how our roofing content reaches the flagship.)
