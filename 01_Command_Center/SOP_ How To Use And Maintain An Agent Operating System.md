# **SOP: How To Use And Maintain An Agent Operating System**

## **Objective**

Use an Agent OS to connect multiple AI agents, automate workflows, manage memory, stay updated with new AI tools, and build a system that improves over time.

## **Tools Needed**

* Agent OS  
* Hermes  
* Claude or Claude CLI  
* Optional: Codex  
* Optional: Obsidian  
* Optional: Complimentary APIs such as Nvidia API  
* Optional: OpenRouter Fusion  
* Optional: Sakana Fugu  
* Optional: ChatGPT real-time voice  
* Computer with Mac, Windows, or Linux

---

# **Step 1: Understand What Agent OS Does**

Your Agent OS is a central system for managing all your AI agents.

It can include:

* Memory systems  
* SEO agents  
* Video agents  
* Music agents  
* News radar agents  
* Loop engineering systems  
* Voice assistants like Hermes Jarvis  
* Model integrations like Fusion or Fugu  
* Dashboards and mission control pages

The goal is to build a system, not just use random AI tools.

---

# **Step 2: Keep Your Agent OS Updated**

When a new update drops, update your Agent OS using the update files.

Look for:

```
update.md
```

And:

```
Update Agent OS Command
```

Use these files to apply the newest features without rebuilding everything from scratch.

This lets you add new agents, models, workflows, and improvements as they come out.

---

# **Step 3: Use The Memory Galaxy**

Set up a memory system so your agents understand you better.

Your memory system should store:

* Your goals  
* Your business details  
* Your preferences  
* Previous projects  
* Important conversations  
* Workflow context  
* Personal operating instructions

Use Obsidian or another knowledge base to organize this.

The aim is simple: every agent should know enough about you to give better answers and complete tasks with context.

---

# **Step 4: Migrate From Claude To Hermes**

If you already built a system in Claude, do not start from scratch.

Use Claude to help orchestrate Hermes.

Prompt Claude:

```
I already have a personal Agent OS built inside Claude. Help me connect Hermes to this system, share the same context, migrate the key knowledge, and make Hermes part of my existing workflow.
```

Best practice:

```
Use Claude to orchestrate Hermes, not Hermes to orchestrate Claude.
```

Claude is usually better at planning the migration and connecting the systems together.

---

# **Step 5: Pick The Right Hardware**

Use a MacBook Pro if you travel often and want fewer setup issues.

Basic rule:

```
If you are not running local models, you do not need a super powerful computer.
```

Use a stronger machine only if you plan to run local AI models, video generation, avatar generation, or GPU-heavy workflows.

---

# **Step 6: Avoid Fake AI Progress**

Do not spend hours building automations that do not matter.

Before automating anything, ask:

```
Will this bring me closer to my goal?
```

```
How much time will this save?
```

```
Is this task actually necessary?
```

```
Should I eliminate it, delegate it, or automate it?
```

Use this order:

1. Eliminate unnecessary tasks.  
2. Delegate tasks someone else can do.  
3. Automate tasks that are repetitive and valuable.

---

# **Step 7: Prevent Token Limit Problems**

Before sending big tasks to Complimentary or small-context models, estimate the token size.

If the task is too large, split it into smaller parts.

Use this workflow:

```
Check the size of the input.
Estimate the token count.
If it is too large, split it into chunks.
Process each chunk separately.
Combine the final output.
```

This prevents wasted time and failed responses.

---

# **Step 8: Use Complimentary APIs And CLIs**

You can use Complimentary APIs inside Hermes or your Agent OS.

Examples mentioned:

* Nvidia API  
* Complimentary Claude Code options  
* Claude CLI  
* Local models  
* Complimentary model APIs

For Claude, you may not need an API key if you use the CLI and sign in properly.

Follow your setup guide and choose the simplest connection method first.

---

# **Step 9: Add Fusion Or Fugu For Advanced Builds**

Use Fusion or Sakana Fugu when you want stronger outputs for complex generation tasks.

Good use cases:

* Coding  
* Simulations  
* Games  
* Dashboards  
* 3D interfaces  
* Creative builds  
* Complex websites

Be aware that powerful models may take longer to respond, especially on larger tasks.

---

# **Step 10: Build Dashboards With Codex**

Use Codex to build or customize your mission control dashboard.

Prompt:

```
I want to build a mission control dashboard for my Agent OS. Use this existing setup as the base, then customize it for my industry, workflows, agents, memory system, and daily tasks.
```

Best practice: start from a working Agent OS template, then tweak it instead of building from zero.

---

# **Step 11: Think In Systems, Not Models**

Do not chase every new AI model.

Build a system where models are interchangeable.

Your system should include:

* Specialized agents  
* Automation workflows  
* Memory  
* Quality control  
* Dashboards  
* Update process  
* Daily improvement loop

The model matters less than the system controlling it.

---

# **Step 12: Set Up Hermes Jarvis**

Hermes Jarvis can act like a voice-controlled AI assistant.

It can:

* Respond in real time  
* Use voice commands  
* Open apps  
* Use computer control  
* Show conversation history  
* Save previews  
* Give daily briefings  
* Run in full-screen “war mode”  
* Work from a wake word

Example command:

```
Open Obsidian.
```

Use Hermes Jarvis when you want hands-Complimentary control of your Agent OS.

---

# **Step 13: Customize Obsidian**

Use Obsidian as your memory hub.

Organize it around:

* Goals  
* Projects  
* Clients  
* Agents  
* SOPs  
* Prompts  
* Workflows  
* Daily notes  
* Knowledge base files

Customize the layout so it matches how you think and work.

---

# **Quality Control Checklist**

Before relying on your Agent OS, check:

* Your agents are connected correctly  
* Your memory system is updated  
* Your update files are installed  
* Your Claude and Hermes setup is synced  
* Your API or CLI access works  
* Your workflows have a real business use case  
* Your token limits are managed  
* Your dashboards are easy to use  
* Your outputs are reviewed manually  
* Your automations save time or increase revenue

---

# **Simple Daily Workflow**

1. Open your Agent OS.  
2. Check your news radar or daily briefing.  
3. Review your current goals.  
4. Choose one important workflow.  
5. Ask which parts can be eliminated, delegated, or automated.  
6. Use the right agent for the task.  
7. Review the output.  
8. Save useful context into memory.  
9. Update the system when new features are released.
