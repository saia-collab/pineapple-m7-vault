## 1. Architectural Blueprint — Karpathy LLM Wiki

This workspace is organized as a **Karpathy LLM Wiki** (a flat, append-only, file-first knowledge graph). The local filesystem is the single source of truth.

```
C:\Pineapple Contractors M7\
├── knowledge-base/
│   ├── raw/                # Untouched drop zone (incoming notes, transcripts, exports)
│   │   ├── pages/          # Raw page-level exports from NotebookLM / web / tools
│   │   └── session-notes/  # Free-form session dumps, brain dumps, transcripts
│   ├── wiki/               # Curated, cross-linked, canonical notes
│   │   ├── index.md        # Master index — links to all wiki entries
│   │   ├── log.md          # Append-only changelog of agent activity
│   │   └── processed.md    # Ledger of raw inputs already promoted into the wiki
│   └── outputs/            # Generated deliverables (campaigns, decks, reports)
├── 01_Command_Center/      # Brand DNA, playbooks, governance (read-only anchor)
├── 02_Media_Vault/         # Raw media pools (bypass: agents read filenames, not bytes)
├── 03_Knowledge_Mat/       # Synthesized SOPs, Obsidian vault, AEO pages
└── 04_Tech_Lab/            # Execution engine, scripts, agent runtime
```

**Karpathy Operating Rules:**
1. **Append, don't overwrite.** New knowledge goes into `raw/` → reviewed → promoted to `wiki/`. The wiki is curated; raw is not.
2. **Filename is API.** Long descriptive filenames (`2026-06-08_meta-ads-paused-framework.md`) beat deep nesting.
3. **Cross-link by relative path.** Inside `wiki/`, use `[link](../other-folder/file.md)` style links so the graph is portable.
4. **One source per fact.** If a number/name/credential is cited, the source file must be in `01_Command_Center/Brand_DNA/` or `03_Knowledge_Mat/`. Otherwise mark `<<VERIFY>>`.
5. **No silent generation.** Every file written begins with an `INTENT:` line.

## 4. Execution Loop
1. **State intent:** Begin every generation with `INTENT: [one sentence]`.
2. **Verify path:** "Am I in the correct room? Am I writing to the correct folder under `knowledge-base/`?"
3. **Verify rule:** "Does this violate the M7 Elite Compliance Filter (Section 2)?"
4. **Verify state:** "If this is an ad layout, is it strictly PAUSED?"
5. **Execute:** Write the file. Log the action to `knowledge-base/wiki/log.md`.
6. **Update ledger:** Add a one-line entry to `knowledge-base/wiki/processed.md` if this generation consumed a raw input.
