# 🔁 PINEAPPLE M7 — DAILY LOOP (3 minutes, never skip)

> You have ADHD. This is built for that. **3 checkpoints. Same every day. No thinking required.**
> If you only do ONE thing: do the **Evening brain-dump**. That alone stops the "I forgot" problem.

---

## ☀️ MORNING (60 sec) — pick the ONE thing
Open **[COMMAND_CENTER_OS.md](COMMAND_CENTER_OS.md)** and paste into Claude:
> "Read SHARED_MEMORY. What's the ONE most important Pineapple task today? Give me the exact next step."

Write that ONE thing at the top of your day. Ignore the other 99 things.

---

## 🌤️ MIDDAY (30 sec) — capture, don't organise
Whenever a thought/idea/SOP update hits you, DON'T file it neatly. Just dump it:
> Paste to Claude: "Capture this to shared memory: [your raw thought]."

Claude sorts it later. Your job is only to catch it, not organise it. That's the ADHD unlock.

---

## 🌙 EVENING (90 sec) — the brain-dump that saves you
Paste to Claude:
> "End of day. Here's what happened: [talk/type freely, messy is fine].
> Update SHARED_MEMORY 'Current State', log it, and tell me the ONE thing for tomorrow."

Claude turns your mess into: an updated brain (SHARED_MEMORY), a log entry (log.md), and tomorrow's ONE thing. **Nothing is forgotten because you never had to file it.**

---

## 💾 END-OF-NIGHT SAVE (Claude runs it) — never lose work again
Paste to Claude:
> "Nightly save: commit today's changes to GitHub (private backup), then remind me what to sync to Google Drive."

**Two backups, two purposes:**
- 🔒 **Private GitHub repo** (`pineapple-m7-vault`, PRIVATE) → the whole vault MINUS secrets (SOPs, memory, Outbox). Your version history + off-machine safety.
- 🌐 **Public GitHub repo** (`Roofing-Marketing-System`) → ONLY brand-compliant marketing (V2 README, creatives, published SEO). Never confidential.
- ☁️ **Google Drive** → the heavy media (`02_Media_Vault`, 39GB) → **frees your local disk**. Keep filenames locally, bytes in the cloud.

> ⚠️ First-time setup needs YOU (auth): a private GitHub repo + Google Drive Desktop signed in. Once wired, the nightly save is one paste. Ask Claude: "Set up my private backup repo."

---

## 📅 FRIDAY (5 min) — the tidy-up (Claude does it)
Paste to Claude:
> "Weekly tidy: merge duplicate notes, promote this week's real SOPs into the Library, archive old dated copies, and give me a 5-line summary of what changed."

---

## The whole system in one line
**Capture messy all week → Claude files it into shared memory → the router serves it back to every tab.**
You never organise. You just talk. The system remembers.
