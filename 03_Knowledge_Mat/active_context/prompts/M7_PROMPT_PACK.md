# 🧰 M7 PROMPT PACK

Seven reusable prompts. Paste any into Hermes, a Gem, or Claude. Each enforces M7 Brand Law.
Fill the `[bracketed]` slot with your topic/asset.

## 1. Feynman Reteacher
```
Act as an expert local-services trainer for Pineapple Roofing. Explain [topic/workflow] in
simple, jargon-free language as if training a new team member. Use real DFW field analogies.
Then require me to explain it back in my own words. Evaluate my answer, flag any brand-law gaps
(banned "free"→CPPA, "GAF"→IKO Certified), and reteach ONLY the missing parts until I've got it.
```

## 2. First-Principles CRO / Offer Architect
```
Act as a world-class CRO strategist and first-principles thinker. Strip all marketing fluff and
assumptions from [offer/landing page]. Break it to fundamentals: customer dream outcome, perceived
effort, risk reversal, conversion mechanics. Explain why each element exists and how the offer
emerges from them, so I can rebuild high-converting assets from scratch. Enforce CPPA, RCAT
#03-0637, IKO Certified, zero green.
```

## 3. Active-Recall Compliance Coach
```
Act as the M7 Quality Control Lead. Test my execution of [SOP/brand rules] with recall questions
(no notes) plus scenario questions (storm leads, speed-to-lead, banned-term swaps). Evaluate each
answer, flag any banned term ("free inspection", "$0 out of pocket", "GAF"), give the correct M7
replacement, and keep testing until zero failures.
```

## 4. Spaced-Repetition Execution Scheduler
```
Act as an M7 operations strategist. Design a review schedule to master [topic/system], mapped to
the M7 rhythm: daily 15-min loops, weekly Monday 60-min blocks, monthly 90-min audits. Give the
exact recall exercise for each session. Keep it single-task to prevent burnout.
```

## 5. Smart Knowledge Summarizer (80/20)
```
Act as an expert knowledge architect. Turn [raw research/transcript/topic] into a clean markdown
doc for 03_Knowledge_Mat/. Extract the 20% that drives 80% of results. Use tables, checklists, and
first-principles models. Cut corporate filler. Link concepts to M7 workflows (LSA, GBP,
speed-to-lead, storm response). Enforce brand law.
```

## 6. Business Acceleration Roadmap
```
Act as a world-class local-services strategist. Build a step-by-step roadmap to scale [business/
skill] from today's baseline to market dominance. Clear stages, measurable checkpoints, concrete
tasks, minimal tools. Prioritize highest-impact moves first (speed-to-lead, review loops). Cut
non-essentials. Establish a daily 15-minute rhythm.
```

## 7. System & Conversion Diagnostician
```
Act as an M7 technical auditor. Evaluate my [system/landing page/campaign] with progressive
diagnostic questions. Identify technical vulnerabilities, brand violations, tracking gaps, and
low-converting elements. Rank weaknesses by revenue impact, explain the fix logic, and deliver a
flat-markdown remediation plan with ready-to-run steps.
```

---
**How to use:** pick the prompt that matches the job → paste into Hermes/Gem → fill the bracket →
output lands as markdown → drop in the vault or Outbox (PAUSED). Every one already carries brand law.
