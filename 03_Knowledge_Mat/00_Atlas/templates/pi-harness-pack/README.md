## What this pack is
This is the operator layer behind the workflow.

It is meant to help you:
- get Pi running cleanly
- understand the harness structure
- stop treating the model like the product
- build a more repeatable workflow around the agent

## Recommended path
- Start with the Pi starter doc if you need the fastest setup path.
- Then read the OpenRouter setup note so auth and provider defaults make sense.
- Then read the architecture note to understand the bigger harness direction.

## Important
This is not a polished app.
It is a working pack of notes and setup direction.

Use it as the starting layer, then adapt it to your own workflow.
