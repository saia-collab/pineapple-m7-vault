🌟 What You're Building

A personal AI headquarters on your own computer. Like an office building 🏢 where every room has a smart helper:

  • 🖥️ A Dashboard — your home screen, one place to see everything.
  • 📎 Paperclip — a whole company of AI agents with a boss, managers, and workers.
  • 🧠 A Memory Vault — your notes, so the AI remembers everything about you.
  • 🦾 Hermes — an AI that actually does multi-step jobs.
  • 🎙️ A voice — talk to it, it talks back.

All of it stays on your machine. Private. Yours. 🔒

🧰 Before You Start (5 min)

You only need two things:

  • 🟡 Node.js → go to nodejs.org → click the big LTS button → install.
  • 🤖 Claude Code → your AI builder that reads the instructions and does the work.
💡 Node.js is the ONLY "techy" install. Everything else, Claude sets up for you.

🪄 The Magic Trick: Let Claude Do It

The system comes as a ZIP folder with a file called SETUP-WITH-AI.md — instructions written for an AI. So you just say to Claude:

"Read SETUP-WITH-AI.md and set up the whole Agent OS
for me on Windows, step by step. Ask me whenever
you need a key or a decision."

That's it. Claude reads the playbook and builds it, stopping to ask you whenever it needs a password or account. 🙋

🪜 The Steps Claude Runs For You

1

🖥️ The Dashboard (the must-have)

Three little commands inside the pack's source folder:

npm install     📦 downloads the parts (a few minutes)
npm run build   🔨 assembles it
npm start       ▶️ turns it on

Open http://localhost:3000 in Chrome. 🎉

⚠️ Always use build then start — NOT "dev mode." Way more stable. 🛡️
2

🧠 Connect Your Memory

Claude points the dashboard at your notes folder so the AI remembers your world.

🪟 Windows gotcha: the folder path needs backslashes (C:\Your\Folder), not forward slashes — or notes won't open. Claude knows this now. ✅
3

🦾 Add Hermes (the do-er)

Needs one cheap key from openrouter.ai (pennies). Claude wires it in.

4

📎 Add Paperclip (your AI company)

One command: npx paperclipai onboard --yes. Claude then builds an org chart — a CEO agent, managers, and workers — right inside your dashboard. 🏢

5

✨ Turn On the Extras (optional)

🎙️ Voice · 🆓 Complimentary coding · 🎬 Video & Thumbnail studios. Claude asks which you want — only add what you'll use. 🧩

🎯 The One Rule That Prevents 90% of Problems

🧠 Different jobs use different AI brains. Don't force one small brain to do everything.

  • Coding → a strong model (Claude)
  • Hermes & voice → an OpenRouter model
  • Quick offline builds → the tiny local model — only here!

✅ You're Done When…

  • 🖥️ Dashboard opens in Chrome
  • 🧠 Your notes show up in the Memory tab (and open when clicked!)
  • 📎 Paperclip shows your AI company org chart
  • 🦾 Hermes answers when you give it a task
