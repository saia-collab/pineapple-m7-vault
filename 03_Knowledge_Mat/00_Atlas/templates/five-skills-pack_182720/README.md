# Five Skills Pack

Open this file first.

## What this is
This pack gives you a few starter skills and prompts so you can get useful outputs faster without inventing every workflow from scratch.

## Included
- `leadmagnet.md`
- `linkedin-post.md`
- `reddit-trends.md`
- `content-writer.md`
- `skill-creator.md`

## How to use it
1. Extract the zip.
2. Read through each file once before dropping anything into your setup.
3. Start with one skill, not all of them at once.
4. Adapt the language to your niche and your workflow.

## Suggested order
1. `reddit-trends.md`
2. `leadmagnet.md`
3. `linkedin-post.md`
4. `content-writer.md`
5. `skill-creator.md`

## Important
This is a starter pack.
Use it as raw material, not as a final system.
