### System Vulnerabilities & Failure Modes

#### 1. Context Inflation & Token Burn
*   *Friction:* Prolonged CLI agent sessions accumulate stale terminal logs, causing model latency (3+ minute responses) and token budget exhaustion.
*   *Mitigation:* Execute session compaction at **60% capacity** using `/compact`. Write a 5-line handoff brief, run `/clear` or `forward/clear`, and re-inject the brief into a fresh context.

#### 2. Review Integrity Loss (Google LSA AI Deletions)
*   *Friction:* Google's AI algorithms quietly delete legitimate 5-star photo reviews.
*   *Mitigation:* Implement the Review Integrity Protocol. Monitor total review counts daily. Upon review deletion, bypass standard support forms and immediately submit a formal escalation to Google LSA Support requesting a **"Market Position Review"**.

#### 3. Remotion Video "Inverted-U" Failure
*   *Friction:* Over-constraining AI video generation with pixel-exact code commands results in stiff, unnatural rendering.
*   *Mitigation:* Pass high-level Spec contracts containing timestamped beat maps, audio sync points, and color tokens, granting the engine creative freedom to compile React components natively.

#### 4. Meta Ads API Permission Failure
*   *Friction:* Automated deployment script fails with permission errors during programmatic ad creation.
*   *Mitigation:* Verify Meta System User has explicit `ads_management` permissions. Ensure the Meta Developer App is set to **LIVE** mode (Development mode blocks programmatic ad creation).
