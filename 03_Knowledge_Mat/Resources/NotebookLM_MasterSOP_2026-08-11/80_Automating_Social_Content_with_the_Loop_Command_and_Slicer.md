### ⏳ THE `/loop` COMMAND: EXPLAINED FOR A 10-YEAR-OLD

#### 🤖 What is a "Normal" AI Chat?
Imagine you have a robot toy. If you say, *"Robot, please draw a picture of a cat,"* the robot draws the cat and stops [cite: 193]. If you want another cat tomorrow, you have to find the robot, turn it on, and ask it **again** [cite: 193]. This means **you** are the one doing all the work to make the robot move [cite: 194]!

#### 🎢 What is the `/loop` Command?
The **`/loop`** command is like **turning your robot into a self-winding alarm clock** [cite: 9, 193]. 

Instead of asking the robot every single day, you say:  
👉 *"Hey robot, every morning at 8:00 AM, wake up, check our Google Search Console for search trends, write a new blog post, and save it inside our Outbox drafts folder as a PAUSED file!"* [cite: 9, 92, 194]

You type that instruction **just once** using `/loop`, and the robot will quietly execute that task **forever in the background** without you ever needing to remind it [cite: 92, 194]! 

```
   [NORMAL CHAT] ──► You ask ──► Robot writes ──► Stop. (You must ask again tomorrow) [cite: 193]
   
   [THE /loop COMMAND] ──► Set clock ──► Runs overnight ──► Saves draft ──► Repeats automatically! [cite: 9, 193, 194]
```

#### 📦 How to Use It for Automated Batches:
When you have a massive project—like generating **50 different variations** of an ad campaign [cite: 9]—doing it one-by-one would eat up your entire afternoon [cite: 240]. 

With `/loop`, you hand the instructions to your local daemon [cite: 9]:
1.  **Set the Goal:** `/goal "generate 50 ad variations"` [cite: 9]
2.  **Attach the Loop Timer:** `/loop 08:00` [cite: 9]
3.  **Go to Sleep:** The system splits the task across your parallel sub-agents overnight [cite: 49]. When you wake up, a beautifully formatted **`MORNING_REVIEW.md`** file is waiting in your `Outbox_Drafts` folder [cite: 9]. You just review, click approve, and get on with your day [cite: 251]!
