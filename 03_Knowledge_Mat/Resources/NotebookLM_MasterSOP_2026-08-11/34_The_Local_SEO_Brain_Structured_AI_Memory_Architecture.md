# The Local SEO Brain: Structured AI Memory Architecture

Instead of treating AI as a standard chat window where you must copy-paste prompts or repeatedly explain your business location, certifications, and target keywords [3, 4], the Local SEO Brain organizes your entire digital presence into an **interlinked, semantic knowledge graph** [5, 6]. ### 🏛️ THE SYSTEM ARCHITECTURE OF THE LOCAL SEO BRAIN

The system is built on **Andrej Karpathy's "hot index and wiki" approach** to structuring AI agent memory [9, 10]. It organizes your data into clean, indexable layers to prevent **context window inflation** (saving you thousands of dollars in token waste while keeping the agent incredibly fast) [9, 11, 12]:

```
                  ┌──────────────────────────────┐
                  │      HOT INDEX & WIKI        │
                  │   (Karpathy Memory Model)    │
                  └──────────────┬───────────────┘
                                 │
         ┌───────────────────────┼───────────────────────┐
         ▼                       ▼                       ▼
 📂 SHORT MEMORY         📂 LONG MEMORY          📂 INTERLINKED ORBS
  Table of Contents,      Permanent SOPs,         Local ZIPs, schemas,
  active target terms     case studies, rules     and competitor NAPs
``` [cite: 60, 61, 132]

1.  **The Hot Index / Table of Contents:** The central map that outlines what files exist, active project cards, and near-term keyword focuses [9, 13].
2.  **Short-Form / Active Context Memory:** Stores your current DFW storm case studies, active leads, and weekly ad campaigns [11, 14]. This keeps active payloads tiny, fast, and sharp [11].
3.  **Long-Form / Permanent Wiki Memory:** Holds your immutable Brand Laws (such as Royal Navy `#1A365D` and Pineapple Gold `#FBC02D` color schemes, the mandatory **Outbox Shield**, and your target ZIP code lists) [15, 16].
4.  **Semantic Interlinking ("The Orbs"):** Every city page, service type, competitor audit, schema file, and customer review is saved as its own document, cross-linked using Obsidian's native `[[wikilink]]` syntax [5, 17].
