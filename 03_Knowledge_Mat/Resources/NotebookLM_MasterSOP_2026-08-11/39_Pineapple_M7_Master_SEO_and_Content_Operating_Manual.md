## 🧹 SECTION 2: THE 2-HOUR ROOM RESET & COMPACTION SOP [cite: 5, 65]
### Preventing Context Window Inflation and API Cost Spikes [cite: 5, 358]

* **The Risk:** Prolonged chat or CLI sessions accumulate massive logs, causing the active model to fettle and stall [cite: 17, 358]. Responses slow to 3+ minutes, and API costs skyrocket as the entire history is sent back and forth on every turn [cite: 17, 358].
* **The Root Cause:** Accumulation of old tool logs, terminal directory readouts, and redundant file drafts inside the active context window [cite: 17].

### Step-by-Step Implementation:

#### Step 1: Track Active Capacity
Monitor context window capacity [cite: 5]. When memory approaches **60% capacity** (Session Compaction) or every **2 hours of active work** (Room Reset), pause active operations [cite: 5].

#### Step 2: Draft the 5-Line Handoff Brief [cite: 5]
Write a highly dense status summary in this exact format [cite: 5, 65]:
1. **Current Progress:** Specific completed files and codebase updates [cite: 5, 17].
2. **Active Files/Tasks:** Current directories, scripts under execution, and task statuses [cite: 5, 17].
3. **Core Rules:** Mandated brand boundaries (no green, CPPA terms, Outbox Shield) [cite: 5, 17].
4. **Tried Approaches:** Failed attempts, syntax debugging notes, and model tests [cite: 5, 17].
5. **Next Steps:** Immediate technical actions to execute in the clean window [cite: 5, 17].

#### Step 3: Run the Compaction CLI Command
Type the terminal compaction command inside the active session [cite: 5]:
```bash
/compact
# or: forward/compact
```
This compresses the conversation history into a single clean summary [cite: 5, 160].

#### Step 4: Execute Room Reset
Execute the clear command to fully flush active memory buffers and erase junk logs [cite: 5, 65]:
```bash
/clear
# or: forward/clear
```

#### Step 5: Resume with Low-Token Tooling
Re-paste the 5-line handoff brief back into the clean context window and ensure token reduction plugins (such as **Headroom** or **Ponytail**) are active to resume work [cite: 5].
