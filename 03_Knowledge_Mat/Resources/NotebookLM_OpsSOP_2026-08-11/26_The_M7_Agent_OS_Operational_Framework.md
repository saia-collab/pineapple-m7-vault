# The M7 Agent OS Operational Framework

These documents serve as a comprehensive **operational guide** for the M7 Agent OS, a specialized system designed to automate marketing and project management for **Pineapple Contractors**. The framework utilizes a **cloud-based infrastructure** involving GitHub for version control, Docker for hosting, and specialized AI agents like **Hermes and Claude** to execute tasks. To ensure quality, the system follows a strict **"Outbox Shield" protocol**, where all AI-generated content is paused for human approval before being published. The manuals detail a **weekly rhythm** focused on SEO growth, social media automation, and lead management while adhering to specific **brand guidelines** and a Polynesian-inspired aesthetic. Ultimately, the system aims to eliminate human error by providing **standardized SOPs** that allow a single operator to manage a complex digital presence efficiently.
