# The Learn Anything Engine: Building Permanent AI Skills

The **Learn Anything Engine** is a powerful feature of the Hermes Agent OS designed to solve the "goldfish memory" problem of AI [1, 2]. Instead of having to re-explain your workflows, rules, and procedures in every new chat session, this engine allows Hermes to ingest any material and distill it into a permanent, reusable skill [1, 3].

Here is a complete breakdown of how the engine works, what it creates, and how it applies directly to your marketing and operations.

---

### 🧠 What is the Learn Anything Engine?
Historically, AI agents would forget the specific steps of a workflow or a company manual the moment a chat session ended, forcing you to re-upload PDFs or copy-paste instructions constantly [3, 4]. 

The Learn Anything Engine allows you to point Hermes at a source—a webpage URL, a text document, a folder of code, or even notes from a task you just completed—and command it to **learn** [4-6]. Hermes then translates that raw information into a structured, executable "recipe" that it retains forever [3, 4].

---

### 📋 The Structure of a "Skill"
When you trigger the engine, Hermes doesn’t just memorize the text; it programmatically authors a **`skill.md`** file [4, 7, 8]. This file is saved locally as a plain markdown note (meaning you can easily open, edit, or delete it yourself) [2, 8]. 

Every skill file Hermes generates is written in plain English and structured to include [2, 7]:
1.  **Name & Description:** What the skill is and its current version [7].
2.  **Trigger Conditions:** When the agent should actively load and use this skill [7].
3.  **Procedure:** The exact step-by-step instructions the agent must execute [7].
4.  **Pitfalls to Avoid:** Warning flags or common errors to watch out for during execution [7].

---

### 🔄 The 5-Step Learning Loop
Teaching Hermes a new operational routine takes about 5 minutes and is entirely code-free [2, 9]:

1.  **Select Your Source:** Identify the guide, GSC keyword data, competitor layout, or SOP you want Hermes to master [1, 4, 5].
2.  **Run the Command:** In your Hermes chat, command line, or via Jarvis Voice, type `/learn` (or `/arn` depending on your version) followed by the URL, folder, or text block [1, 8, 9].
3.  **Hermes Drafts the Skill:** The agent analyzes the resource and automatically drafts a clean, structured `skill.md` file [7, 8].
4.  **Approve the Write:** If you have approval gates turned on, Hermes will show you the draft. Once you confirm, it commits the file to your workspace memory [10].
5.  **Execute on Demand:** The next time you need that work done, you simply call the skill by name (e.g., `/skill agent-operating-system`) [5, 8]. Hermes loads the recipe on demand and executes it without any further explanation [3, 8].
