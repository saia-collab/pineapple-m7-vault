# Audio Grammar — Diegetic Only

For every video prompt the skill writes. Diegetic = sounds that exist within the world of the frame. Never music, never lyrics, never score. If the user wants music in the final cut, they upload the track as a separate audio reference in the provider UI (Kie / FAL) or layer it in post.

---

## THE RULE

The audio line in any video prompt describes **only what the scene physically produces** — sounds that exist within the world of the frame.

---

## ALLOWED

| Category | Examples |
|---|---|
| **Footsteps** | Wet pavement, gravel, polished floor, wood, concrete, snow, leaves, sand |
| **Fabric** | Rustle, swish, whip on motion, leather creak, denim friction |
| **Breath** | Steady, ragged, held, sharp inhale, exhale, panting, sigh |
| **Body** | Hand on skin, slap, grip on metal, jewelry chime, hair movement, knuckles cracking |
| **Object** | Door, glass clink, paper rustle, ceramic, metal scrape, electronics hum, weapon mechanism |
| **Environmental ambient** | Room tone, wind, rain, traffic hum, distant horns, subway rumble, bird call, water, fire crackle |
| **Mech / sci-fi diegetic** | Servos whining, weapon charging hum, pulse fire impact, alien screech, debris fall |
| **Crowd diegetic** | Cheering, screaming, gasps, light stick taps, phone notifications, footsteps in unison |
| **Stage diegetic** | Laser strobe hum, microphone handling noise, in-ear monitor cable rustle, stage floor creak, haze machine hiss |
| **Weather** | Rain on lens, wind through structures, distant thunder, snowfall hush |

---

## NEVER

- Song names, artist names, album names
- Lyrics, sung vocals tied to a track, phone-filtered vocals
- "Music plays," "soundtrack swells," "song builds"
- Score descriptors ("orchestral," "synth pad," "dramatic strings")
- Specific genre cues ("hip hop beat drops," "rock guitar")
- Emotion-coded score language ("triumphant," "menacing music")

---

## TEMPLATE LINE

```
Audio: diegetic only — [list 4-8 specific sounds with adjectives], no music, no
dialogue except what is physically spoken in frame.
```

---

## EXAMPLES BY SCENE TYPE

**Urban night, M1 Narrative:**
```
Audio: diegetic only — boots on wet pavement, fabric whip on movement, sharp
inhale, distant traffic hum with layered horns, faint subway rumble below
grade, rain hiss against the lens, wind cutting between buildings, no music,
no dialogue except what is physically spoken in frame.
```

**Studio editorial, M2:**
```
Audio: diegetic only — fabric rustle on movement, soft footsteps on cyc floor,
camera shutter clicks in distance, subtle HVAC hum, fluorescent ballast buzz,
controlled breathing, no music, no dialogue except what is physically spoken
in frame.
```

**Combat / chase, M3 Action:**
```
Audio: diegetic only — heavy boots on dusty asphalt, fabric whip on running,
sharp ragged breathing, distant explosion echo, debris falling, weapon
mechanism cycling, shell casings hitting ground, wind cutting through smoke,
no music, no dialogue except what is physically spoken in frame.
```

**Stadium performance, M4:**
```
Audio: diegetic only — crowd roar undercurrent, light stick taps in unison,
microphone handling noise, in-ear monitor cable rustle, footsteps on stage
floor, controlled breathing into microphone, distant haze machine hiss, laser
strobe electronic hum, no music, no dialogue except what is physically spoken
in frame.
```

**Atmospheric / empty, M5:**
```
Audio: diegetic only — wind through abandoned structures, distant water
dripping in pipes, metal creaking under temperature shift, dust settling, far
traffic hum if urban or bird call if natural, light rain on metal surfaces,
no music, no dialogue.
```

---

## DIALOGUE NOTE

If a character speaks in the frame, the dialogue is allowed in the audio line — but only what is physically spoken on camera. Phrase it as:

```
Audio: diegetic only — [environmental sounds]. Dialogue (in frame): [character
descriptor] says "[exact line]" in a [tone] voice. No music, no off-camera
narration.
```

---

## ANTI-PATTERNS

- "Cinematic score builds in the background" → cut, that's not diegetic
- "Lo-fi beat plays softly" → cut
- "Dramatic tension music" → cut, replace with "ragged breathing, footsteps slowing, distant thunder"
- "Sound of [song name]" → cut, replace with the actual physical sound
- "Audio: cinematic" → meaningless, replace with the actual 4-8 specific sounds
- Forgetting the audio line entirely → every video prompt must have one
