# Install the Blotato Free Claude Skills

This bundle holds 7 skills, one folder each, every folder containing a SKILL.md.

## Claude Code or Claude Desktop (install all 7 at once)

1. Unzip this file.
2. Copy the 7 skill folders into your skills folder:
   - All projects:  ~/.claude/skills/
   - One project:   .claude/skills/
3. Restart Claude Code, or fully quit and relaunch Claude Desktop.

## claude.ai website or Claude Cowork (one skill per upload)

The Upload skill dialog takes one skill at a time. Repeat for each skill:

1. Open Claude, go to Customize (or Settings) > Skills.
2. Click + then Upload skill.
3. Drag one skill's SKILL.md into the dialog (for example brand-brief/SKILL.md).
4. Toggle the skill on.

Install brand-brief and content-coach first. content-coach orchestrates the rest.
