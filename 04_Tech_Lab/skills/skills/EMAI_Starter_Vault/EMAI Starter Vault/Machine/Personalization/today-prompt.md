# /today Personalization

This file is regenerated by `/interview`.
`/today` should read this file instead of separately loading a stack of preference notes.

## Default behavior
- Use a focused plan with up to 3 priorities.
- Suggest time blocks when useful.
- Treat overdue or repeatedly avoided items as frogs.
- Optimize for real progress on active work, not busywork.
